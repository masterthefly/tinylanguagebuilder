TinyLanguageBuilder

Build a small language model right here, on your own CPU: pre-train it, teach it a task, and chat with it. No GPU, no server, no account. Your text never leaves this browser tab.

3. Teach it a task

Pre-training teaches a model to continue text. Fine-tuning shows it examples of an instruction and a good answer, so it learns to follow it. Use the built-in task (write a sentence that uses a given word), or teach it your own examples.

Examples to learn from

Choose a file with one example per line.

What goes in the file?

One JSON object per line, with a prompt and the response you want back:

{"prompt": "Opposite of hot:", "response": " cold"}
{"prompt": "Opposite of up:", "response": " down"}

The model is later asked exactly the prompt you type, so put any layout (such as Q: and A:) in the prompt, and start each response with a space. You need at least 20 lines (about 10% are held back for scoring) and each prompt plus response must fit in the model's 64-token window, roughly 40 words. A few hundred examples of one narrow task work best; this is a very small model.

    Save or share the model

    Put the files in one folder and the command-line tool can use them: tlm chat --model folder --input "dragon"

    Open a model from files

    Choose model.safetensors and tokenizer.json (and sft.json to ask it questions). Models made by the tlm command-line tool work too. An opened model can generate text but not train.
